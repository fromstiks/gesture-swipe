# GestureSwipe — листание ленты жестом руки без касания экрана

Android-приложение: фронтальная камера отслеживает ладонь через **MediaPipe HandLandmarker**,
а взмах рукой вверх/вниз превращается в свайп в текущем приложении (TikTok, Reels, Shorts…)
через **AccessibilityService**. Удобно, когда руки грязные/мокрые.

## Как это устроено

```
Камера (CameraX, фронталка)
        │  кадры RGBA
        ▼
HandLandmarkerHelper ──► MediaPipe: где сейчас ладонь (Y-координата)
        │  y ∈ [0,1] каждый кадр
        ▼
SwipeDetector ──► взмах вверх/вниз? (по скорости движения ладони, с cooldown)
        │  UP / DOWN
        ▼
SwipeAccessibilityService ──► dispatchGesture(): реальный свайп по экрану
```

Камера крутится в **foreground-сервисе** (`GestureCameraService`), поэтому продолжает
работать, когда ты свернул это приложение и открыл TikTok.

## Файлы

| Файл | Что делает |
|------|-----------|
| `MainActivity.kt` | Экран настройки: 3 кнопки (камера → служба → запуск) |
| `GestureCameraService.kt` | Foreground-сервис с камерой + распознаванием |
| `HandLandmarkerHelper.kt` | Обёртка над MediaPipe HandLandmarker |
| `SwipeDetector.kt` | Логика «взмах вверх/вниз» из потока координат |
| `SwipeAccessibilityService.kt` | Эмуляция свайпа через Accessibility API |

## Запуск

### 1. Открыть в Android Studio
Открой эту папку как проект в **Android Studio** (Hedgehog или новее).
Дай ему подтянуть Gradle и зависимости (нужен интернет при первой сборке).
Файл `gradle-wrapper.jar` и `local.properties` Android Studio создаст сам.

### 2. Скачать модель MediaPipe
Положи файл `hand_landmarker.task` в `app/src/main/assets/`
(подробности — в `app/src/main/assets/PUT_MODEL_HERE.txt`). Прямая ссылка:

```
https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task
```

### 3. Собрать и поставить на телефон
Подключи Android-телефон (Android 8.0 / API 26 и выше) с включённой отладкой по USB
и нажми **Run ▶** в Android Studio.

### 4. Настроить на телефоне (3 кнопки по порядку)
1. **Дать доступ к камере** — разреши камеру (и уведомления на Android 13+).
2. **Включить службу свайпов** — откроются системные настройки спец. возможностей,
   там вручную включи «GestureSwipe». *(Это единственный способ — Android не даёт
   включать accessibility-службу программно, из соображений безопасности.)*
3. **Запустить распознавание** — стартует фоновый сервис с камерой.

### 5. Пользоваться
Открой TikTok. Помаши ладонью **вверх** перед фронтальной камерой → следующий ролик,
**вниз** → предыдущий.

## Калибровка (почти наверняка понадобится)

Пороги в `SwipeDetector.kt`:

- `minDelta` (0.20) — насколько сильно должна пройти ладонь. Ловит ложные срабатывания?
  Увеличь до 0.25–0.30. Приходится махать слишком размашисто? Уменьши до 0.15.
- `cooldownMs` (900) — пауза между свайпами. Пролистывает по 2 ролика за раз? Увеличь.
- `windowMs` (350) — за какое время должен уложиться взмах.

Скорость/длину самого свайпа по экрану — в `SwipeAccessibilityService.kt`
(`GESTURE_DURATION_MS` и доли `fromFraction`/`toFraction`).

## Честные ограничения

- **Батарея и нагрев.** Камера + нейросеть в фоне заметно едят заряд. Не для «весь день».
- **Ложные срабатывания.** Любая рука/лицо в кадре может дёрнуть ленту. Пороги помогают, но не идеально.
- **Google Play.** Приложения с AccessibilityService жёстко модерируются. Для себя — без проблем; для публикации в маркете — сложно.
- **Только Android.** На iOS так управлять чужим приложением нельзя без джейлбрейка.
- Направление свайпа зависит от того, как повёрнут телефон и камера — если вверх/вниз перепутаны, поменяй местами `swipeUp`/`swipeDown` или знак в `SwipeDetector`.

## Идеи развития
- Отдельный жест (например, кулак) как «активатор», чтобы случайные движения не листали.
- Наэкранный оверлей с превью камеры для отладки жестов.
- Горизонтальные свайпы (лайк/меню).
